# BELIVE MONEY — édition de lecture adaptée

Voir [BELIVE_MONEY_manuscrit_final.pdf](BELIVE_MONEY_manuscrit_final.pdf) et [BELIVE_MONEY_manuscrit_final.docx](BELIVE_MONEY_manuscrit_final.docx).

**Attention :** l’utilisateur a fourni le manuscrit en conversation, pas sous forme d’un fichier DOCX. Cette livraison conserve les 39 chapitres et leur progression, mais réécrit et condense les paragraphes. Elle n’est pas une transcription intégrale. Voir [QA_livre.md](QA_livre.md) avant toute diffusion.

Sources maintenables : `production/contenu.py`, `production/annexes.py`, `production/compose.py` ; ressources d’image : `illustrations/`. Pour reconstruire : créer un environnement Python avec `python-docx`, `reportlab`, `pillow` et `pypdf`, puis lancer `python production/compose.py`.
